# PKarchives — media pack

Assets promotionnels générés à partir de la démonstration locale de l’interface.

| Fichier | Usage |
|---|---|
| `../assets/banner-1544x500.png` | Bannière App Store / page projet |
| `../assets/card-1200x630.png` | Carte de partage / aperçu |
| `../screenshots/01-vue-principale.png` | Capture de la vue principale |
| `../screenshots/02-historique-annuel.png` | Capture de l’historique annuel |
| `demo.mp4` | Master 16:9, 1280×720, 8,7 s |
| `../gifs/demo-interface.gif` | GIF léger, 960×540, 12 fps |
| `../gifs/apple-style/01-archivage-mockup.gif` | Démonstration animée claire avec mockup |
| `../gifs/apple-style/02-interface-dark.gif` | Démonstration animée compacte sur fond sombre |
| `../gifs/apple-style/03-interface-dynamic.gif` | Démonstration scénarisée : clic, progression, transfert et historique |
| `dynamic-interface-demo.mp4` | Master vidéo de la démonstration dynamique |
| `variants/pkarchives-square.mp4` | Déclinaison carrée 1:1 |
| `variants/pkarchives-reel.mp4` | Déclinaison verticale 9:16 |

Le master est la version de référence : il montre le curseur, le parcours d’archivage
et les états de l’interface. Les déclinaisons sont des exports de diffusion dérivés du
master, adaptés aux formats sociaux.
